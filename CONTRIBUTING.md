# Contributing

Thanks for considering a contribution!

1. Open an issue to describe a bug or a proposed feature.
2. Fork the project and make your change in a descriptive branch.
3. Keep the application dependency-free where practical, and test code changes.
4. Run `node --test tests/math.test.js` if Node.js 18+ is installed.
5. Open a pull request explaining the change and how you tested it.

Please be respectful and avoid submitting secrets or private personal information.
