# Creative Size Toolkit

A free, lightweight, privacy-friendly **image dimension and aspect ratio calculator** for social media creators and designers.

## Features
- Common presets for Instagram, stories, YouTube, and A4 print
- Simplified aspect ratio, orientation, and pixel count
- Live visual proportion preview
- Swap dimensions and copy dimensions
- Works without accounts or APIs; no tracking, and calculations run in your browser
- Accessible labels and responsive layout

## Run locally
Download the project, extract it, and open `index.html` in a browser. No installation is required.

## Test
If you have Node.js 18+ installed:

```bash
node --test tests/math.test.js
```

## Publish on GitHub Pages
1. Upload these project files to a **public** GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select **main**, folder **/(root)**, then **Save**.
5. Once GitHub deploys the site, its URL will appear in Pages settings.
